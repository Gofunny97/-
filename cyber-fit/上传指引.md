# NEON//FIT — 上传指引（国内手机可访问）

> **结论先说**：不要再在 Cloudflare 上折腾了。`pages/upload` 入口已被官方下线，Cloudflare 新推的 Workers 又给不了国内可连的域名。
> **推荐改用腾讯云 EdgeOne Pages —— 国内直连、免备案、拖 zip 即上线。**

---

## 为什么 Cloudflare 这条路走不通

两个原因，都不是你操作的问题：

**① Pages 上传入口已下线**
`https://dash.cloudflare.com/pages/upload` 现在返回 404（你刚看到的）。Cloudflare 已把 Pages 标记为**维护模式**——官方文档页开头直接挂着一句「Are you sure you want to use Pages?」，并把新项目全部导向 Workers。

**② 新入口给的域名在国内照样打不开**

| 域名形态 | 国内手机 | 来源 |
|---|---|---|
| `xxx.workers.dev` | ❌ 基本打不开 | Cloudflare 新入口（唯一可用的） |
| `xxx.pages.dev` | ⚠️ 勉强，偶尔不通 | Cloudflare（入口已关闭） |
| `xxx.edgeone.app` | ✅ 直连免备案 | 腾讯云 EdgeOne Pages |

根因：Cloudflare 赠送的免费二级域名**未备案**，拿不到大陆 CDN 节点。电脑能开往往是因为有代理，手机则直接超时。

## ✅ 推荐方案：腾讯云 EdgeOne Pages

### 第 1 步 · 登录

访问 **`edgeone.ai`**（腾讯云国际站），用**微信 / QQ** 登录最省事，无需实名。

> 国内入口也可搜「腾讯云 EdgeOne Pages」，但国际站 `edgeone.ai` 免备案额度更宽松。

### 第 2 步 · 找到上传入口

登录后按顺序点：

```
左侧菜单 → EdgeOne Pages（或 Pages）
        → 上传文件 / Upload
```

> 如果首页看到的是「立即体验」按钮，直接点它，进度会跳过绑定域名环节。

### 第 3 步 · 拖 zip

把工作空间里的 **`neonfit-deploy.zip`** 直接拖进上传框。

已经帮你打包并验证过结构：

```
404.html                 失效链接兜底页
index.html               主应用（172KB）
manifest.webmanifest     PWA 配置
sw.js                    Service Worker
icons/ (5 个图标文件)
```

`index.html` 位于压缩包根层，没有多余嵌套，上传后不会 404。

### 第 4 步 · 拿网址

约 30 秒，得到形如：

```
https://xxxxxxxx.edgeone.app
```

**这个网址国内手机可以直接打开。**

### 第 5 步 · 装到手机桌面

用**手机浏览器**打开上面的网址：

| 系统 | 操作 |
|---|---|
| Android / Chrome | 右上角 `⋮` → **安装应用** |
| iPhone / Safari | 底部 **分享** → **添加到主屏幕** → 添加 |

应用内首页也有安装横幅可点。

装好后：**桌面有霓虹图标、全屏无地址栏、断网也能用**。

## 备选方案

### 备选一 · Cloudflare（仅当你只打算在电脑/海外用）

虽然入口变了，但仍可上传：

```
Workers & Pages → Create application
                → 拖入 neonfit-deploy.zip
                → 部署
```

拿到 `xxx.workers.dev` 域名。**电脑能用，国内手机大概率打不开。**

如果一定要 Cloudflare 且需要国内可访问，唯一办法是**绑定自有域名**（几十元/年 + 备案 1–2 周），把域名指向 Cloudflare 走其 CDN。有域名后 `workers.dev` 的阻断问题就不存在了。

### 备选二 · GitHub Pages（需能访问 GitHub）

你提到 GitHub 登录困难，这条路目前不通。若日后网络改善可用：

1. 新建 Public 仓库
2. **Add file → Upload files**，把 zip **解压后的** 9 个文件和 `icons` 文件夹拖进去
3. **Settings → Pages** → Source 选 `Deploy from a branch` → branch `main` → 目录 `/ (root)`

本项目所有资源引用都用 `./` 相对路径，**已适配子路径部署**，放在 `/仓库名/` 下也能正常工作。

## 常见问题

**Q：换平台后我的数据还在吗？**
A：数据存在浏览器的 `localStorage` 里，按「浏览器 + 域名」隔离。换网址 = 换存储空间，**不会自动迁移**。

迁移方法：在旧网址点右上角「数据库」图标 → **导出 JSON** → 到新网址 → **导入 JSON**。训练、体重、饮食数据都能完整恢复（照片需重拍）。

**Q：zip 上传后打开是 404？**
A：说明压缩包里多套了一层文件夹。正确结构是解压后**直接**看到 `index.html`，而不是 `neonfit/index.html`。用随附的 zip 可避免。

**Q：桌面图标显示默认灰色图标？**
A：`manifest.webmanifest` 或 `icons/` 没上传成功。检查它们是否与 `index.html` 同级。

**Q：需要备案吗？**
A：用 EdgeOne 免费二级域名 **不需要备案**。只有绑自有域名走国内 CDN 才需要。

**Q：手机提示"无法访问"但电脑正常？**
A：还是 `workers.dev` 域名被阻断。必须换成 EdgeOne 域名。

**Q：会不会自动挂掉？**
A：EdgeOne Pages 免费套餐个人使用足够。Service Worker 已缓存全部资源，之后断网也能打开。
