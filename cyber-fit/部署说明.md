# NEON//FIT — 部署与安装指南

单文件应用，**完全离线可用**。部署后可以添加到手机桌面，像原生 App 一样全屏运行。

---

## 一、先搞清两件事

| 你想做的事 | 需要什么 |
|---|---|
| 在电脑上正常使用 | 双击 `index.html`，什么都不用做 |
| 手机上装成 App（全屏、有图标、断网可用） | 需要一个 http(s) 网址 → 部署 |

**为什么本地打开不能"安装"？** 浏览器要求 Service Worker 必须运行在 http(s) 环境，这是安全策略限制，不是应用的问题。所以想要桌面图标，就需要先拿一个网址。

---

## 二、部署到 Cloudflare Pages（推荐主线）

**特点**：不用 GitHub、不用命令行、不用配置构建，注册只要邮箱，拖上去就有网址。

### 第 1 步 · 注册

打开 `dash.cloudflare.com/sign-up`，用邮箱注册并验证。免费额度对个人静态站完全够用。

### 第 2 步 · 新建项目

登录后进入控制台，按下面任一入口进入 Pages：

- 左侧菜单 **Workers 和 Pages** → 右上角 **创建** → **Pages**
- 或直接访问 `dash.cloudflare.com/pages/new-project`

### 第 3 步 · 直接上传（关键一步）

在「创建 Pages」页面选择：

```
连接到 Git      ← 跳过这个
仅部署静态资产   ← 选这个
```

点击 **「上传资产」**，然后：

1. 项目名称填 `neonfit`（网址就是 `neonfit.pages.dev`，被占用就换个名）
2. 拖入**整个 `cyber-fit` 文件夹**
3. 点击 **「部署站点」**

等 30 秒左右，页面会显示 `https://neonfit.pages.dev`。

> **提示**：务必上传 `cyber-fit` 这个文件夹本身，不要把里面的文件散着拖。图标在 `icons/` 子目录里，散拖会丢失目录结构导致图标加载失败。

### 第 4 步 · 装到手机

用**手机浏览器**打开 `https://neonfit.pages.dev`，然后：

- **Android / Chrome**：右上角 `⋮` → 「安装应用」（应用内也有安装横幅可点）
- **iPhone / Safari**：底部 **分享** 按钮 → 「添加到主屏幕」→ 「添加」

装好后从桌面图标启动：**无地址栏全屏运行、启动更快、断网也能用**。

### 第 5 步 · 更新应用

改完代码后，回到同一个 Pages 项目，上传新文件夹会生成新的部署版本，网址不变。Service Worker 检测到新版本时会自动更新。

## 三、其他部署方式（备选）

### Vercel（同样拖拽，无需 GitHub）

1. 访问 `vercel.com/new`，用邮箱登录
2. 找到 **「拖放文件夹」** 区域
3. 把 `cyber-fit` 文件夹拖进去
4. 点 **Deploy**，几十秒后得到网址

### GitHub Pages

适合以后想用 git 管理版本的情况。注意 GitHub 在国内有时登录不畅，且需要配置 token。

1. 在 GitHub 新建仓库（Public）
2. 仓库页面 → **Add file** → **Upload files**，把 `cyber-fit` 内所有文件和 `icons` 文件夹一起上传
   - 注意：是上传**文件夹内部**的内容，`index.html` 要在仓库根目录
3. 仓库 → **Settings** → 左侧 **Pages**
4. Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`
5. 保存，1–3 分钟后刷新页面显示网址

### 本机临时服务器（仅自己用）

电脑和手机连同一 WiFi，在本文件夹打开终端：

```bash
python -m http.server 8000     # Windows
python3 -m http.server 8000    # macOS / Linux
```

查电脑 IP（`ipconfig` 看 IPv4，或 `ifconfig | grep "inet "`），手机访问 `http://电脑IP:8000/index.html`。

⚠️ 电脑关机或换网络后需重新启动。

## 五、数据说明

所有数据只存在**你自己设备的浏览器里**，不上传任何服务器：

| 数据类型 | 存储位置 |
|---|---|
| 训练记录、体重、饮食 | `localStorage` |
| 餐食照片 | `IndexedDB` |

**这意味着**：

- 数据不跨设备同步 —— 换手机要重新开始
- 清除浏览器数据会导致记录丢失
- 建议定期导出备份：右上角「数据库」图标 → **导出 JSON**，存到网盘或发给自己

迁移设备时，在新设备上「导入 JSON」即可完整恢复（照片需重新拍摄）。

## 六、常见问题

**Q：部署后打开是白屏？**
A：多半是上传时把文件散拖了，丢了目录结构。删掉站点重新上传整个文件夹，确认 `index.html` 和 `icons/` 是同级关系。

**Q：图标不显示 / 安装横幅不出来？**
A：同上，检查 `icons/` 文件夹是否完整上传。

**Q：Android 提示"无法安装"？**
A：确认是用 `http://` 或 `https://` 打开的网址，而不是双击本地文件。

**Q：装到桌面后数据没了？**
A：数据按「浏览器 + 域名」隔离。必须从桌面图标进入，不要用无痕模式或另一个浏览器打开。

**Q：能改成自己的名字吗？**
A：可以。搜索 `NEON//FIT` 替换为你想要的文字即可，`manifest.webmanifest` 里的 `name` / `short_name` 是桌面上显示的名称。

**Q：需要联网吗？**
A：直接双击 `index.html` 就能用全部功能，只是没有桌面图标和全屏模式。

## 七、文件清单

部署时这些文件都需要上传：

```
cyber-fit/
├── index.html              主应用（CSS/JS 全内联）
├── 404.html                访问不存在的地址时显示的返回页
├── manifest.webmanifest    PWA 配置：名称、图标、独立窗口模式
├── sw.js                   Service Worker，负责离线缓存
└── icons/
    ├── icon.svg            矢量图标源文件
    ├── icon-192.png        Android / 浏览器标签图标
    ├── icon-384.png        中等尺寸
    ├── icon-512.png        主图标 + Android 自适应图标
    └── apple-touch-icon.png iOS 桌面图标
```

`部署说明.md` 是给人看的文档，上传时可以排除。

## 八、Cloudflare Pages 专属提示

**几个容易踩的坑**：

| 现象 | 原因 | 解决 |
|---|---|---|
| 打开是白屏 | 上传时把文件散着拖，丢了 `icons/` 目录结构 | 删除站点，重新上传**整个文件夹** |
| 桌面图标是默认图标 | `manifest.webmanifest` 没上传成功 | 检查文件是否在上传列表里 |
| 安装横幅不出现 | 未通过 https 访问 | 确认网址是 `https://neonfit.pages.dev` |
| 修改后没生效 | 浏览器缓存了旧 Service Worker | 等待片刻自动更新，或强制刷新一次 |

**免费额度**：Cloudflare Pages 个人静态站免费，无流量和请求次数限制，唯一的限制是单次上传文件数不超过 20,000 个 —— 本项目只有 10 个文件，完全不担心。

**绑定自定义域名**（可选）：Pages 项目 → **Custom domains** → 添加域名。需要在 Cloudflare 那边配 DNS 记录，之后网址就能用自己的域名。
